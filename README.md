# Kali Linux in Browser 🐉💻
شغل كالي لينكس بواجهة رسومية كاملة من تلفونك عن طريق GitHub Codespaces

### 🚀 كيف تشغلو؟

1. اضغط على زر `Code` الأخضر فوق
2. اختار تبويب `Codespaces`
3. اضغط `Create codespace on main`
4. انتظر 2-3 دقائق لحدي ما يجهز
5. أول ما يفتح، دوس على رابط `Port 6080` التحت (Forwarded)
6. دوس `Connect` واكتب الباسورد: `12345678`

مبروك! كالي شغال في المتصفح بواجهة XFCE 😎

### 🔧 المواصفات
- **النظام:** Kali Rolling
- **الواجهة:** XFCE4
- **المتصفح:** Firefox
- **الباسورد:** 12345678
- **المستخدم:** kali / kali
